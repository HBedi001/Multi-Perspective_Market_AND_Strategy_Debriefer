# Multi-Perspective Market & Strategy Debriefer Agent

An agentic technical evaluation pipeline built with **LangChain (LCEL)** and the **ReAct (Reason + Act)** pattern. This system performs balanced, multi-perspective strategy audits on stock market setups by separating bullish opportunity discovery from adversarial risk stress-testing.

Built as part of **Nisarg's AI Master Class (Session 3: Agentic Architectures & Tool Calling)**.

---

## Architecture Overview

Standard single-prompt LLM interactions often succumb to confirmation bias—overemphasizing technical setups while ignoring downstream market risks. 

This agent uses a multi-tool execution loop orchestrated by `create_agent`:

User Input (Ticker & Context)
│
▼
[ReAct Agent Orchestrator] (ChatOpenAI: gpt-4o-mini, temp=0.2)
│
├──► 1. Tool: draft_bullish_thesis
│       - Isolates trend, structural support, volume confirmations, and price targets.
│
├──► 2. Tool: stress_test_risk_factors
│       - Cross-examines bullish output against negative divergences, overhead supply,
│         and broader market breadth (e.g., sector ETF divergence).
│
▼
[Executive Strategy Debrief]

Setup Snapshot

Core Analytical Tension

Actionable Triggers (Entry Confirmation vs. Hard Invalidation)

Final Stance: [Aggressive Long / Cautious Long / Neutral-Wait / Avoid]


---

## Core Components

* **Deterministic Sampling (`temperature=0.2`)**: Enforces strict mathematical and technical consistency, minimizing speculative hallucinations.
* **LangChain `@tool` Integration**: Worker methods use explicit typing and detailed Python docstrings that serve as functional tool descriptions for the LLM planner.
* **Adversarial Chaining**: Tool 2 (`stress_test_risk_factors`) takes the raw context *and* the output generated by Tool 1 (`draft_bullish_thesis`) to audit every optimistic assumption.
* **ReAct Scaffolding**: Directs the agent to reason through indicators, call necessary tools, observe results, and synthesize a structured debrief without conversational fluff.

### Executive Debrief

#### Setup Snapshot
The asset has pulled back to the 50-day EMA at $220, a critical structural support level, on declining volume indicative of easing sell-side pressure. A bullish Stochastic crossover from sub-20 confirms localized momentum stabilization, though the 4-hour XLK negative divergence warns of broader sector friction.

#### Core Tension
A primary conflict exists between localized oversold exhaustion at major daily moving average support versus macroscopic momentum degradation across the broader technology sector.

#### Actionable Triggers
- Confirmation Trigger: High-volume daily reversal bar closing above $222.50.
- Hard Invalidation Line: Decisive daily close below the 50-day EMA ($220.00).

#### Final Stance
Cautious Long: Valid technical floor with favorable risk/reward, but risk-managed via reduced initial position sizing due to sector-level headwind.

Key Takeaways from Session 3
Agents vs. Simple Chains: While LCEL handles linear prompt | llm chains, complex multi-perspective audits require agents capable of dynamic tool routing and downstream context passing.

Docstrings as Schemas: In modern LangChain, function docstrings serve as the prompt context that informs the LLM's tool-selection logic.

Adversarial Synthesis: Chaining opposing perspectives (opportunity vs. risk) produces grounded, institutional-grade outputs rather than generic LLM summaries.
